# VibeFrontend 最小原型

设计文档见仓库根目录的 `可视化界面与语义逻辑设计工具.md`。这个原型只实现了其中最核心的一部分，用来试用“摆容器 → 写说明和逻辑 → 交给 Agent → 预览交互”这条流程。

## 运行

需要 Node.js 和 Rust（含 Windows 上的 MSVC 构建工具）。

```bash
npm install
```

```bash
npm run tauri dev
```

第一次运行要编译 Rust 依赖，需要几分钟。启动后打开的是仓库里的 `project/` 文件夹。要打开别的设计项目，启动前把环境变量 `VF_PROJECT` 设为那个文件夹的路径。

只想在浏览器里看界面时，可以运行 `npm run dev`，再打开 <http://localhost:1420>。这时文件读写走 `vite.config.ts` 里的开发接口，功能与桌面窗口相同。两种方式都使用 1420 端口，不能同时运行。

## 已实现

- 素材栏：容器、外部容器，“收藏的素材”（跨项目复用，按结构哈希与 `.designer/origins.json` 来源记录识别“已修改 / 有新版本 / 两边都改过”，拖进还没有它的项目时自动复制到 `components/`），`project/components/` 中的控件（自动列出，可拖入或右键收藏），以及基础图形、流程图图形、线条和“我的预设”（拖入，或点一下再在设计窗口里拖出来）
- 画图（参照 Figma / FigJam）：在左侧素材栏点一下图形或线条，选为当前工具（素材栏里会标出来），再在设计窗口里拖出大小，或者点一下放默认大小；也可以直接从素材栏拖进来。快捷键：V 选择、R 矩形、O 椭圆、L 直线、Shift+L 箭头、X 连接线、T 文字、Esc 退出当前工具。Shift 画正方形和正圆、线的角度按 45 度取整，Alt 从中心画
- 素材栏里的容器、外部容器和控件也一样：点一下选为工具，再在设计窗口里拖出大小（只点一下就按默认大小放一个）；或者直接拖进来
- 吸附开关、网格、撤销和重做放在设计窗口上方右边，和缩放控件在同一行
- 线条：直线、折线、曲线，六种端头，线中间可以写字。两头可以挂在形状或控件上，被挂的东西移动时线跟着走；选中线后拖两端的圆点改挂。挂的规则：靠近某一边的中点（12 像素以内）挂在中点；靠近外轮廓（10 像素以内）挂在轮廓上的那一点；按在形状或控件里面，朝着另一头自动选边；其他地方不挂。形状按真实轮廓算（星形、三角形、云都是），不按方框；容器和外部容器只能挂在边上；两头不会挂在同一个东西上；按住 Ctrl 不挂
- 自动吸附：移动、缩放、画图时吸附到其他东西的边和中线（红色参考线），吸附到等间距的位置（粉色间距标记），可选吸附网格（4、8、10、16）；按住 Ctrl 临时关闭
- 样式条：选中形状或线条时浮在它旁边，换形状、配色（12 种配色，一次换填充、描边和文字）、自定义颜色、线型、线宽、圆角、边数、角数、端头、路径、字号、对齐、粗体；新画的图形沿用上次用过的颜色和线型
- 预设：把选中图形的样式存为预设，存在设计项目的 `ui/presets.json`，出现在素材栏“我的预设”里，右键可以删除
- 双击形状或线条写字；Ctrl+D 复制一份；Ctrl+Enter 快速新建（在右边或下边放一个同样的形状，用折线箭头连起来）；Shift 拖动只沿一个方向；Shift 拖角保持长宽比
- 视角：按住鼠标中键拖动、或者按住空格再用左键拖动，平移设计窗口；滚轮上下平移，Shift + 滚轮左右平移；Ctrl + 滚轮（触控板双指捏合）以鼠标所在的点为中心缩放，10% 到 400%；Ctrl + = / Ctrl + - 放大缩小，Ctrl + 0 回到 100%，Shift + 1 缩放到刚好装下整个窗口。设计窗口四周留有空白，可以把视角移到窗口外面。中间栏右侧有缩放比例和按钮
- 画布操作的撤销和重做（Ctrl+Z、Ctrl+Shift+Z），按保存过的画布版本回退，不包括 YAML 和文档的修改
- 多选：按住 Shift 点画布，或者按住 Shift / Ctrl 点图层，加选或取消；Ctrl+A 全选窗口里最外面一层。多选后可以整体拖动（整体吸附）、方向键移动、删除、复制一份；全是形状或全是线条时，样式条的改动作用到全部
- 框选：从空白处拖出方框，和方框有交叠的都选中；从一个还没选中的容器上拖，框选的是容器里面的东西（和 Figma 在画框里拖一样）；按住 Shift 框选是加选
- 复制（Ctrl+C）、剪切（Ctrl+X）、粘贴（Ctrl+V）：内容是一段 JSON，放在系统剪贴板里，可以贴到另一个设计项目。选中一个能装东西的节点时贴进它里面，否则贴在同一层；连续粘贴每次往右下错开 16 像素。复制的东西之间的连线跟着一起复制，连到外面的线头停在原位置。只复制画布，不复制 YAML 里的逻辑
- 折线的拐点：选中折线后，每一段中间有一个小把手，拖它把这一段平移（也会吸附到别的东西的边和中线）；拖挨着两头的那一段时，会在中间折出一小段。被挂的形状移动后，第一段和最后一段自动保持横平竖直。样式条里的“重置折线”回到自动算出的走法
- 图层列表
- 设计窗口的编辑模式：选中、拖动、八个方向缩放、方向键微调、Delete 删除、从素材栏拖入
- 右键菜单：复制引用、打开说明、编辑逻辑、添加条件、还原为容器、置于顶层或底层、删除；图层里右键也是同一个菜单
- 引用：把选中的东西复制成一行英文 `User referenced "键=值; ..."`，带文件路径和行号，贴给 Agent。可以引用控件（右键菜单或右上角的“引用”按钮）、文档或 YAML 中选中的几行（页签上的“引用所选”）、素材栏里的一种控件（右键）、问题栏里的一条问题（右键）；没有选中控件时，“引用”按钮引用整个项目
- 在右侧顶部直接修改控件 ID，YAML 中的引用同步更新
- 设计窗口的预览模式与顶部“▶ 独立预览”窗口：控件接收鼠标事件，逻辑运行，文字条件可切换，可重新开始，按住 Alt 点击选中控件并打开说明
- 逻辑运行层：状态、符号条件与文字条件、属性计算、绑定、事件按批处理、全局事件（`app.start`、`window.click`、自定义事件与 `emit`）
- 状态的归属（界面自己管、业务管）和业务事件：预览时业务事件走模拟步骤，事件记录里能看到
- 效果：控件显示和隐藏时的过渡，预览时播放；带效果的控件在图层里标“需翻译”，问题栏列出每个效果当前的哈希
- 导出成 Qt（命令行，见下一节）
- 右侧“文档”和“YAML”页签：文档支持“源码 | 预览”切换和所见即所得编辑（未改动的段落保留原文，小节和锁定标记受保护），停止输入后自动保存
- 问题栏：YAML 语法、未知的状态路径或条件代号、控件不支持的属性和事件、找不到的说明小节等
- 事件记录
- 监听项目文件夹，外部修改后自动刷新；YAML 写坏时沿用上一份有效逻辑

## 导出成 Qt

```bash
npm run export:qt -- <设计项目文件夹> [导出到哪个文件夹]
```

不写导出位置时，用设计项目 `project.json` 里的 `export.qt`。导出的是一个分好层的 Qt 6 工程（CMake），单独构建它就得到一个不接业务的预览程序。

- 工具生成的文件每次整个覆盖；交给 Agent 写的界面效果层（`ui_effects/`）只在不存在时放一份起始文件，之后不再碰。
- 内容没变的文件不重写；上一次生成过、这一次不再需要的文件会被删掉（只删导出记录 `vf-export.json` 里记着的）。
- 导出器会报告接口相对上一次导出变了什么，同样的内容写在导出文件夹的 `INTERFACE.md` 里。
- 设计项目里有错误时不导出。

同一串操作步骤可以在工具这一侧跑一遍，用来和导出的 Qt 程序比较：

```bash
npm run case -- <设计项目文件夹> "click:某个控件;state"
```

完整的例子、构建办法和验证结果见仓库的 `examples/minimal/README.md`。设计项目里和导出有关的写法见 `project/README.md` 第 9 节。

目前导出支持的范围：一个窗口；控件按画布上的位置和尺寸摆放（还没有布局）；写了 `qt` 对应关系的控件导出成对应的 Qt 控件，没写的导出成占位框；显示隐藏的过渡效果。导出还没有做成工具界面里的按钮。

## 还没有实现

- 调用动作（`call` 和 `actions`）、动作模拟
- 锁定、版本的恢复与重做
- 旋转、多选后的整体缩放、对齐和分布按钮
- 基础图形和线条导出成 Qt（目前导出后是占位框）
- 直线和曲线不能加拐点（只有折线可以）
- 设计窗口与编辑器界面之间的 iframe 隔离（目前控件直接画在编辑器页面里，靠 CSS `@scope` 限定样式）
- 删除控件时不会询问是否一并删除 YAML 条目，残留的条目会在问题栏报错

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/main.ts` | 编辑器界面：素材栏、图层、设计窗口、右侧页签、问题栏 |
| `src/library.ts` | 收藏的素材、来源记录（`.designer/origins.json`）、状态对比与跨项目复制 |
| `src/structhash.ts` | 控件的结构哈希（忽略名字与说明、统一换行和 JSON 键顺序） |
| `src/docview.ts` | 文档页签的“源码 \| 预览”切换与所见即所得编辑 |
| `src/previewwindow.ts` | 独立预览窗口（`▶ 独立预览`）与跨窗口 Alt+点击联动 |
| `src/model.ts` | 设计项目的数据结构和查找函数，不碰网页和文件 |
| `src/runtime.ts` | 逻辑运行层，不依赖网页和 Tauri；导出时原样打包进 Qt 程序 |
| `src/expr.ts` | 表达式的解析与求值 |
| `src/loader.ts` | 把项目文件读成数据。文件怎么读由调用方提供，工具界面和命令行共用 |
| `src/check.ts` | 检查设计项目，结果显示在问题栏 |
| `src/project.ts` | 工具界面里读取项目：在 `loader.ts` 之上加载控件和效果的实现、注入样式 |
| `src/md5.ts` | MD5，用来算效果的哈希 |
| `src/shapes.ts` | 基础图形和线条：形状的轮廓、线的走法和端头、自带的预设和配色 |
| `src/snap.ts` | 自动吸附：对齐、等间距、网格 |
| `src/viewport.ts` | 设计窗口的视角：平移和缩放；`viewport-init.ts` 在页面加载后启用它 |
| `src/paint.ts` | 把形状和线条画成 SVG，以及素材栏里的小图标 |
| `src/export/qt.ts` | 导出成 Qt：从项目内容算出要生成哪些文件，不读写磁盘 |
| `src/export/qt-code.ts` | 导出时随项目变化的那些 C++ 和接口清单 |
| `src/export/qt-runtime.ts` | 嵌进 Qt 的 JS 引擎运行的入口，连同逻辑运行层一起打包 |
| `src/export/dump.ts` | 把状态和各控件应有的样子写成一行 JSON，两边比较用 |
| `qt-templates/` | 导出工程里固定不变的文件（CMake、界面绑定层的固定部分、给 Agent 的规则） |
| `scripts/export-qt.ts` | 导出的命令行入口：读项目、打包逻辑、写文件 |
| `scripts/run-case.ts` | 在工具这一侧按步骤跑逻辑的命令行入口 |
| `src/refs.ts` | 生成引用：算出控件、条目、小节和选区在文件中的行号 |
| `src/fs.ts` | 文件读写接口，桌面窗口里调用 Rust，浏览器里调用开发接口 |
| `src-tauri/src/lib.rs` | Rust 系统层：读、写、列目录、监听 |
