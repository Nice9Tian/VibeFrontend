# 灯光面板

这个窗口用来开关三盏灯。它同时是 VibeFrontend 原型的示例项目，用到了鼠标事件、全局事件、条件和绑定。

<!-- ui-section: lamp -->
## 灯

一盏灯是一个圆形的指示灯，下面写着房间名。点击切换开和关，亮的时候发出暖黄色的光。
鼠标移上去时略微放大，按下时缩小一点，让用户知道它是可以点的。
程序正在启动时不能点击。
<!-- /ui-section -->

<!-- ui-section: all-off-button -->
## 全部关闭按钮

一次关掉所有的灯。没有灯亮着的时候不可用，避免用户点了没有反应。
<!-- /ui-section -->

<!-- ui-section: hint-box -->
## 提示框

鼠标移到某盏灯上时出现，用一句话告诉用户“点击可以切换这盏灯”。
现在它还是一个没有转换的容器，可以交给 Agent 做成一个带圆角和浅色背景的提示条。
